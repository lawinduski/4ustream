# 4uStream Phase 4 — Professional Ads System

Implemented the advertising campaign layer without rebuilding the existing app.

## Included
- Audience targeting: all / free / VIP.
- Placement types: banner / popup / inline.
- Campaign scheduling with optional start and end times.
- Priority + order sorting.
- Popup frequency control with a 20-second default.
- Popup close lock with a 5-second default countdown.
- Session-based frequency tracking per ad.
- Mobile-specific ad image support.
- Existing admin ad editor expanded with campaign controls.
- Existing VIP users remain ad-free on the public site.
- Active/scheduled ads are filtered before rendering.

## Compatibility
Older ad documents remain compatible through defaults:
- audience = all
- priority = 0
- frequencySeconds = 20
- skipAfterSeconds = 5
- placement = banner
