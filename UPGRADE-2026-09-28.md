# 4uStream Professional Upgrade

This version upgrades the existing 4uStream project in place. It does not replace the architecture.

## Included

- Professional Film / Drama Content Studio with sections for:
  - Basics and release information
  - Poster, backdrop, transparent logo and trailer
  - Primary playback URL + player type
  - Multiple servers with URL, player type, quality and FREE/VIP access
  - WebVTT subtitle tracks
  - Quality labels and Skip Intro
  - Rating, runtime, IMDb ID, genres, tags and country/language
  - Director and cast / character metadata
  - Screenshots / gallery
  - SEO title, description and keywords
- Admin user controls for VIP duration and active/disabled status.
- Immutable admin audit log for create/update/delete, VIP and status changes.
- Branding provider is now mounted globally so saved branding is actually used across the site.
- WebVTT subtitle upload from the admin panel, with Storage size/type restrictions.
- Firebase App Check support via an optional reCAPTCHA Enterprise site key.
- Verification-email API now requires an authenticated Firebase ID token matching the requested email.
- Service-worker cache version bumped so deployed updates activate cleanly.
- Extra .gitignore protection for local build metadata and old auth-user files.
- Stream player server switching fixed so changing a server actually reloads video/HLS playback.
- HLS quality selection display corrected.
- PWA manifest uses the dedicated app icons.

## Required Vercel server environment

Keep these server-only variables private:

- `FIREBASE_ADMIN_PROJECT_ID`
- `FIREBASE_ADMIN_CLIENT_EMAIL`
- `FIREBASE_ADMIN_PRIVATE_KEY`
- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASS`

Client Firebase variables remain `NEXT_PUBLIC_*` as usual. Optional App Check:

- `NEXT_PUBLIC_FIREBASE_APPCHECK_SITE_KEY`

## Firebase rules

Deploy both `firestore.rules` and `storage.rules` after reviewing them in the Firebase Emulator / console. Storage now permits admin image uploads under `public-assets/**` and admin `.vtt` uploads under `public-assets/subtitles/**`, with size/type checks.

## Important

Video and embed URLs must be content the site operator is authorized to redistribute. The project does not attempt to bypass provider protections.
